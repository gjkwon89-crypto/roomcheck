현장심사 실별 점검 - 아이패드 설치·사용 안내

────────────────────────────
[1] 인터넷 주소 만들기 (처음 한 번, 무료 · PC에서)
────────────────────────────
아이패드 홈 화면 앱은 https 주소에서 한 번 열어야 설치됩니다.
GitHub Pages 사용 (무료, 계속 유지됨)

 1. github.com 가입 → 오른쪽 위 [+] → New repository
    - Repository name: roomcheck (아무 영문 이름)
    - Public 선택 → Create repository
 2. "uploading an existing file" 클릭
    → 이 폴더의 파일 7개(index.html, sw.js, manifest.webmanifest,
      icon-180.png, icon-192.png, icon-512.png, 설치방법.txt)를 모두 끌어 넣기
    → 아래 [Commit changes]
 3. 저장소 상단 Settings → 왼쪽 Pages
    → Branch: main, 폴더: / (root) → Save
 4. 1~2분 뒤 위쪽에 주소가 생김:  https://아이디.github.io/roomcheck/

 ※ 이 주소에는 화면(프로그램)만 올라갑니다.
   점검 데이터와 사진은 아이패드 안에만 저장되고 밖으로 나가지 않습니다.

────────────────────────────
[2] 아이패드에 설치
────────────────────────────
 1. 아이패드 Safari로 위 주소 열기 (인터넷 연결된 상태)
 2. 주소창 옆 공유 버튼(□↑) → "홈 화면에 추가" → 추가
 3. 이후로는 반드시 홈 화면 아이콘으로만 사용
    (Safari 안에서 연 화면과 데이터가 따로 저장됩니다)
 4. 아이콘으로 한 번 열고 나면 인터넷 없이도 열립니다.

────────────────────────────
[3] 매일 백업 (중요)
────────────────────────────
 · 홈 화면 아이콘을 지우면 앱 안의 데이터·사진도 지워집니다.
 · 하루 작업이 끝나면:
   [데이터 표·백업] 탭 → [전체 백업 저장] → [공유 → "파일에 저장"]
   → 나의 iPad › 현장심사 폴더에 저장
 · 위쪽 주황색 "백업 필요" 표시가 초록색으로 바뀌면 완료.
 · 백업 ZIP 안 "사진" 폴더에 분야(실내환경안전/시설안전/외부환경안전)·동별로 사진이 들어 있습니다 (파일 이름에 층·실 이름 포함).
 · 500MB가 넘으면 여러 개로 나뉘어 저장됩니다(모두 저장하세요).

────────────────────────────
[4] 복원 (새 아이패드 / 다시 설치했을 때)
────────────────────────────
 [데이터 표·백업] → [백업 불러오기] → 파일 앱에서 백업 ZIP 선택
 (나뉜 파일은 한 번에 모두 선택)
 · 끝난 프로젝트 정리: 맨 위 [− 프로젝트 삭제] → 확인
   (이 아이패드의 해당 프로젝트 실·사진만 지워짐 · 먼저 백업 권장)

────────────────────────────
[5] 앱을 고친 뒤 반영하기
────────────────────────────
 · GitHub 저장소에 바뀐 index.html을 다시 올릴 때
   sw.js 맨 위 VERSION = 'RCA-v4' 숫자를 하나 올려서(RCA-v5) 같이 올립니다.
 · 아이패드에서 인터넷 연결된 상태로 앱을 두 번 열면 새 버전이 됩니다.
 · 데이터는 그대로 유지됩니다. (그래도 올리기 전에 백업 권장)

────────────────────────────
[6] 실명 글자인식 (아이패드 내장 '텍스트 스캔')
────────────────────────────
 1. [실명 글자인식] 버튼 → 입력칸이 열리고 키보드가 뜹니다
 2. 입력칸을 한 번 더 탭 → 메뉴의 [텍스트 스캔]
    (안 보이면 [자동 완성 ›] 안, 또는 메뉴 끝 › 로 넘겨서)
 3. 실명판을 비추고 [삽입] → 확인 없이 실 이름에 자동으로 들어갑니다
 · 인터넷 필요 없음. 여러 줄이 읽히면 한글이 들어간 글자만 골라 넣습니다.
 · 텍스트 스캔은 iPadOS 15 이상, A12 칩 이상 아이패드에서 지원됩니다.
 · 메뉴에 아예 없으면: 설정 → 일반 → 언어 및 지역 → 라이브 텍스트 켜기

────────────────────────────
[7] 현장심사기록지 PDF 출력 (A4)
────────────────────────────
 1. [현장심사기록지] 탭 → [PDF 출력]
 2. 아이패드: 인쇄 옵션 화면 위쪽 공유 버튼(□↑) → [파일에 저장] 하면 PDF로 저장
    PC: 대상(프린터)을 'PDF로 저장'으로 고르고 저장
 · A4 세로, 쪽마다 제목·프로젝트명과 아래 가운데 쪽번호(현재쪽 / 전체쪽)가 들어갑니다. 상단 메뉴·버튼은 인쇄되지 않습니다.

────────────────────────────
[8] 보완차수 (최초심사 → 1차 보완 → 2차 보완 …)
────────────────────────────
 1. 맨 위 프로젝트 옆 차수 목록 → [+ 보완차수 추가]
    · 직전 차수의 동·층·실·입력값을 그대로 복사해서 시작 (사진·첨부는 차수마다 따로)
 2. 보완된 항목만 고치고, 실마다 [자료 업로드]로 보완 사진·PDF를 올립니다
 3. 현장심사기록지: 제목에 (1차 보완) 표시 + 직전 차수 대비 '보완완료' 실과 '신규' 미흡 표시
 · 차수 목록에 차수별 마지막 수정일이 보이고, 실 화면 위쪽에 그 실의 수정일이 보입니다
 · 이전 차수도 언제든 다시 골라 수정할 수 있습니다
 · 잘못 만든 차수는 차수 목록의 [− n차 보완 삭제]로 지웁니다
 · 전체 백업에 모든 차수와 첨부가 함께 들어갑니다
